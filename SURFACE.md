# Surface

The public API of every product, generated by `Scripts/surface-report.sh` from the
symbol graphs — one line per public symbol, its declaration and the first sentence of
its documentation. Regenerate after changing the surface; CI fails when this file is stale.
The generated schema (`MottoCDA`, re-exported by `MottoOTTCore`) is the CDA's own and is not listed.
